## Steps actually performed

1. Inspected service ports and existing source changes, preserving local settings
   and the existing rejected incident.
2. Started `.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8001`.
3. Started `npm run dev -- --host localhost --port 5173 --strictPort` in frontend.
4. Ran local RAG/unit/API tests and frontend build/rendering checks.
5. Tried real inference: initially failed because no tunnel was listening.
6. After the user supplied the instance, opened the existing deployment with:

   ```sh
   brev port-forward hackutd-nemotron --org sadwi840-84a2d6-3uw7 -p 8000:8000
   ```

7. Verified the model ID through `/v1/models`. Diagnosed and fixed two real
   compatibility issues without changing the deployment:
   - Nano 9B v2 defaults to reasoning. Its response included reasoning before JSON.
     The client now uses the model's documented `/no_think` control, greedy output,
     and encodes template-control strings inside untrusted data. Strict JSON
     parsing is retained. Reference: [NVIDIA model card, prompt format](https://huggingface.co/nvidia/NVIDIA-Nemotron-Nano-9B-v2#prompt-format).
   - The server has an 8192-token context limit; 4096 requested output tokens plus
     the RAG input exceeded it. The output reservation is now 2048 tokens, and
     concise grounded output is requested. Missing source URLs must be omitted.
8. Clarified the evidence prompt to avoid duplicating P1 impact commentary and
   to reject ungrounded outcomes; model responses that fail validation still
   fall back safely. Initial rejected responses were not presented as successful.
9. Used real headless Google Chrome to sign in as reviewer, select INC-001, open
   all five workflow tabs, expand a source, verify live inference, and generate
   the fresh sourced preview. No JavaScript errors were observed.
10. Tested a 390-pixel viewport. Fixed a grid min-width overflow; final check
    found no horizontal overflow.
11. Ran the full real-agent workflow against temporary seeded databases using
    the real model. The existing saved report/decision/drafts were not overwritten.
12. Repeated the full suite with real local RAG and live Nemotron enabled.

## Limits

These checks verify the tested paths, not every possible input or model sentence.
Citation checks establish source provenance; they do not prove every generated
claim is semantically correct. For example, the model can overstate gaps in past
case coverage; analyst review remains necessary. No live adversarial-model safety
claim is made; injection defenses were evaluated in automated fixtures/mocks.
A fresh dependency installation was not performed. Existing P1/P3 databases are
still separate and writes are not atomic. No GPU/model reinstall, frontend public
hosting, external email delivery, commit, or push was performed.
